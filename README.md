# Brain Age Gap (BAG) Models & Mortality Analysis

This repository contains the collection of modeling and statistical analysis code, organized and sanitized for publication.

## Repository Structure

- **`Data/`**: Contains only the minimum necessary variables required by each regression notebook. Family identifiers (`householdid`) have been anonymized and replaced with generic numeric codes (`10001`, `10002`...) while maintaining data consistency for longitudinal cross-references (`uid` = `householdid_particid`).
- **`Results/`**: Folder designated for storing intermediate regression results generated by the main notebooks.
- **`Models_fitted/`**: Folder for saving the `.pkl` files of the trained Machine Learning models.
- **`SFS/`**: Contains the `.pkl` files for the pre-calculated Sequential Feature Selection to avoid excessive retraining times.
- **`Figures/`**: Directory where the generated plots and figures are saved.
- **`BBAGs-Mortality/`**: Subfolder containing scripts grouped by stages:
  - **`Wave1/`**: Initial regression models.
  - **`Wave1_Performance/`**: Performance metrics corresponding to Wave 1.
  - **`Mortality_Models/`**: Survival analysis (Cox Proportional Hazards) and mortality data merging.
  - **`Wave2/`**: Incidence regression models (Wave 2).
  - **`Wave2_Performance/`**: Performance metrics corresponding to Wave 2.
  - **`Supplementary/`**: Auxiliary models (e.g., healthy control subjects only CN/HC).
  - **`Stats_Report/`**: Descriptive statistical reports and tables.
